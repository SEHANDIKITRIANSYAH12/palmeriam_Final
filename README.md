# SIPALMI - Sistem Informasi Pelayanan Kelurahan Palmeriam

## 📋 Tentang Project

**SIPALMI** (Sistem Informasi Pelayanan Kelurahan Palmeriam) adalah platform digital terintegrasi yang dirancang untuk mempermudah akses masyarakat terhadap berbagai layanan administrasi, informasi, dan saluran pengaduan di Kelurahan Palmeriam, Jakarta Timur.

Platform ini dibangun dengan teknologi modern untuk memberikan pengalaman yang user-friendly, transparan, dan efisien dalam pelayanan publik.

---

## 🎯 Visi & Misi

### Visi
Mewujudkan Kelurahan Palmeriam yang modern, transparan, dan melayani dengan teknologi digital.

### Misi
Meningkatkan kualitas pelayanan publik berbasis teknologi untuk kemudahan dan kepuasan masyarakat.

4. Siapkan dokumen sesuai yang tertera
5. Datang ke kantor kelurahan dengan dokumen lengkap

**Manfaat untuk Masyarakat:**

**Manfaat untuk Kelurahan:**

### 4. 📝 **Pengaduan Masyarakat**
Sistem pengaduan online dengan tracking untuk memudahkan masyarakat menyampaikan keluhan dan aspirasi.

**Fitur:**
- Form pengaduan online yang mudah diisi
- Generate Ticket ID otomatis untuk tracking
- Tracking status pengaduan real-time
- Kategori pengaduan (Infrastruktur, Pelayanan, Lingkungan, dll)
- Prioritas pengaduan (Rendah, Sedang, Tinggi)
- Notifikasi status pengaduan

**Cara Menggunakan:**

**Mengajukan Pengaduan:**
1. Klik menu "Pengaduan" atau tombol "Ajukan Pengaduan"
2. Isi form pengaduan dengan lengkap:
   - **Judul Pengaduan** - Ringkas dan jelas
   - **Kategori** - Pilih kategori yang sesuai
   - **Deskripsi** - Jelaskan masalah secara detail
   - **Nama Pelapor** - Nama lengkap
   - **Kontak** - Nomor HP yang bisa dihubungi
   - **Email** (opsional) - Untuk notifikasi
   - **Lokasi** - Lokasi kejadian/permasalahan
   - **Prioritas** - Pilih tingkat urgensi
3. Klik "Kirim Pengaduan"
4. **PENTING:** Simpan **Ticket ID** yang diberikan
5. Ticket ID akan tersimpan otomatis di browser Anda

**Melacak Status Pengaduan:**
1. Klik "Lacak Pengaduan" di halaman pengaduan
2. Masukkan Ticket ID yang Anda terima
3. Klik "Lacak"
4. Lihat status pengaduan:
   - **Baru** - Pengaduan baru diterima
   - **Diproses** - Sedang ditangani oleh kelurahan
   - **Selesai** - Pengaduan telah selesai ditangani
5. Anda juga dapat melihat detail lengkap pengaduan

**Manfaat untuk Masyarakat:**
- ✅ Dapat mengajukan pengaduan kapan saja tanpa harus datang ke kantor
- ✅ Dapat melacak status pengaduan secara real-time
- ✅ Lebih mudah menyampaikan keluhan dan aspirasi
- ✅ Mendapatkan respon yang lebih cepat
- ✅ Transparansi proses penanganan pengaduan

**Manfaat untuk Kelurahan:**
- ✅ Mengurangi antrian di kantor untuk pengaduan
- ✅ Meningkatkan efisiensi penanganan pengaduan
- ✅ Memiliki database pengaduan yang terorganisir
- ✅ Dapat memprioritaskan pengaduan berdasarkan urgensi
- ✅ Meningkatkan akuntabilitas dan transparansi
- ✅ Meningkatkan kepuasan masyarakat

## 🔐 Panel Admin

- Tambah berita baru

**Cara Menggunakan:**
1. Klik menu "Berita"
2. Klik "Tambah Berita" untuk membuat berita baru
3. Isi form:
   - Judul berita
   - Kategori
   - Konten berita
   - Upload gambar
   - Status (Terbit/Draft)
4. Klik "Simpan"
5. Untuk edit, klik ikon edit di daftar berita

#### 4. **Kelola Agenda**
- Tambah agenda kegiatan
- Edit agenda
- Hapus agenda
- Informasi lengkap (tanggal, waktu, lokasi, peserta)

**Cara Menggunakan:**
1. Klik menu "Agenda"
2. Klik "Tambah Agenda"
3. Isi informasi:
   - Judul kegiatan
   - Tanggal dan waktu
   - Lokasi
   - Kategori
   - Jumlah peserta

#### 5. **Pengaturan Akun**
- Ubah profil admin (nama, username)
- Ubah password

## 📦 Instalasi & Setup

### Prerequisites
- Node.js (v18 atau lebih baru)
- npm atau yarn
- Git

### Langkah Instalasi

1. **Clone Repository**
```bash
git clone <repository-url>
cd palmeriam-digital-village
```

2. **Install Dependencies Frontend**
```bash
npm install
```

3. **Install Dependencies Backend**
```bash
cd server
npm install
```

4. **Setup Database**
```bash
cd server
npx prisma generate
npx prisma migrate dev
```

5. **Setup Environment Variables**

Buat file `.env` di folder `server`:
```env
DATABASE_URL="file:./dev.db"
JWT_SECRET="your-secret-key-here"
PORT=3000
```

6. **Jalankan Development Server**

Terminal 1 (Backend):
```bash
cd server
npm run dev
```

Terminal 2 (Frontend):
```bash
npm run dev
```

7. **Akses Aplikasi**
- Frontend: http://localhost:8080
- Backend API: http://localhost:3000
- Admin Panel: http://localhost:8080/admin/login
